# EZITECH Cyber Security Internship

Welcome to my Cyber Security Internship repository at EZITECH.

This repository documents my learning journey, practical tasks, projects, and hands-on experience in cybersecurity and cloud security.

The main goal of this internship is to develop practical cybersecurity skills, understand security concepts, and learn how to identify and address security risks in real-world environments.

## Internship Objectives

- Understand cybersecurity fundamentals.
- Learn networking and Linux fundamentals.
- Explore cloud security and cloud infrastructure.
- Understand identity and access management (IAM).
- Learn storage security and permissions.
- Practise security logging and monitoring.
- Identify cloud security misconfigurations.
- Understand security benchmarks and best practices.
- Learn network security and access controls.
- Develop technical documentation and reporting skills.
